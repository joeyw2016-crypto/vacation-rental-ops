## 2. Loom description (paste as-is)

> In this demo I show an AI assistant for vacation rental operations, built on Telegram. Guests message the bot in plain language and get a simple service menu: book, check availability, modify a booking, or talk to a human. The host side runs entirely on spreadsheets — every booking becomes a row, every property status is one cell, and edits take effect in Telegram immediately, with zero code and zero restart. The demo covers: instant booking with order numbers, live availability, change requests, human escalation with admin forwarding, and spreadsheet-to-chat sync. Built to evolve: LLM-powered natural replies, Slack/email notifications, and a real database are ready to plug in.

## 3. One-paragraph case summary (for Upwork proposals / portfolio)

> I built a vacation rental operations assistant that lives inside Telegram. Guests send a normal message — "I'd like to book AD-101" or "there's a water leak" — and the bot responds with a clean service menu: book, check availability, modify, or escalate to a human. Bookings are created instantly with real order numbers and the property is marked occupied to prevent double-bookings. The owner manages everything in plain spreadsheets (property catalog + booking log): add a property, change a price, or flip a status, save the file, and the bot reflects it on the next guest message. No code, no restarts. Urgent issues can be forwarded to an admin chat automatically. The system is built to scale — LLM replies, Slack/email alerts, and database migration are already designed in.
